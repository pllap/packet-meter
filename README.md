# Packet Meter

Windows 알림 영역에서 네트워크 활동을 선풍기 아이콘으로 보여 주는 작은 프로그램입니다. 아이콘을 클릭하면 선택한 네트워크 어댑터의 초당 수신·송신 패킷 수와 바이트 수를 함께 확인할 수 있습니다.

![다크·라이트 모드 아이콘 미리보기](docs/fan-preview.gif)

## 기능

- 수신·송신 패킷/초 및 바이트/초 표시
- 수신과 송신 바이트 속도의 합에 따라 선풍기 회전 속도 조절
- Windows 시스템 테마에 맞춘 흰색·검은색 아이콘
- 활성 어댑터 자동 선택 또는 직접 선택
- 측정 주기 100~60,000ms 설정 및 재시작 후 유지

10 KB/s 이하에서는 선풍기가 멈춥니다. 전송량이 증가하면 회전이 빨라지고, 100 MB/s 이상에서는 약 0.9회전/초로 제한됩니다. 1 KB는 1,024 B 기준입니다. 음악·영상·다운로드를 구분하지 않으며 선택한 어댑터의 전체 트래픽을 사용합니다. 스트리밍의 사전 버퍼링 등으로 움직임이 일정하지 않을 수 있습니다.

## 빌드와 실행

Windows와 .NET Framework 4.x에 포함된 C# 컴파일러가 필요합니다. 별도의 SDK나 패키지 설치는 필요하지 않습니다. PowerShell에서 저장소 루트로 이동한 뒤 실행하세요.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
.\dist\PacketMeter.exe
```

실행 파일은 `dist/`에 생성되며 Git에 포함되지 않습니다. 알림 영역에서 선풍기 아이콘을 왼쪽 클릭하면 상세 창이 열리고, 오른쪽 클릭하면 어댑터·측정 주기를 설정하거나 종료할 수 있습니다. 아이콘이 보이지 않으면 알림 영역의 `^` 안을 확인하세요. 상세 창을 닫아도 프로그램은 계속 실행됩니다.

기본 자동 선택은 **기본 게이트웨이가 있는 첫 번째 활성 어댑터**를 사용합니다. 여러 네트워크가 연결된 경우 Windows의 실제 기본 경로와 다를 수 있으므로 필요하면 메뉴에서 직접 선택하세요. 직접 선택한 어댑터는 재시작하면 자동 선택으로 돌아갑니다.

측정 주기는 `%LOCALAPPDATA%\PacketMeter\settings.ini`에 저장합니다. 숫자는 측정 주기와 관계없이 실제 경과 시간으로 나눈 초당 값이며, 시작 직후나 어댑터 전환 직후에는 이전 값이 없어 잠시 `--`로 표시됩니다. 패킷 내용은 읽지 않습니다.

## 테스트

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\test.ps1
```

속도 서식과 회전 속도 기준, 설정 저장·복원, 선풍기 프레임의 색상과 투명도를 확인합니다. 테스트 결과물은 `.test-output/`에 생성됩니다.

## 코드 안내

- [src/PacketMeter.cs](src/PacketMeter.cs): 프로그램 전체 소스. 클래스와 주요 함수에 한글 주석이 있습니다.
- [docs/architecture.html](docs/architecture.html): 클래스·함수·데이터 흐름을 정리한 안내서. 저장소를 내려받은 뒤 브라우저로 열어 보세요.
- [tests/PacketMeter.Tests.cs](tests/PacketMeter.Tests.cs): 실행 가능한 기본 테스트.

Windows 작업 표시줄에 별도 창을 겹치지 않고 알림 영역 아이콘을 사용합니다. 회전은 GIF나 SVG를 직접 재생하지 않고 미리 만든 48개 아이콘 프레임을 교체하는 방식입니다. Windows의 알림 영역 갱신 상황에 따라 움직임이 조금 끊겨 보일 수 있습니다.
