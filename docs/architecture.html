01 / Orientation

이 문서를 읽는 방법

이 프로그램의 중심은 MeterContext입니다. 운영체제에서 통계를 읽고, 속도를 계산한 뒤, 알림 영역 아이콘과 상세 창을 갱신합니다. 나머지 클래스는 설정, 숫자 표현, 그림, 창을 각각 담당합니다.

대상 소스 · Packet Meter v8의 PacketMeter.cs. 아래 줄 번호는 이 버전 기준입니다. 저장소를 내려받아 이 파일을 열면 링크에서 소스 파일도 확인할 수 있습니다.
INPUT

선택한 어댑터의 누적 패킷·바이트 수

CALCULATE

이전 값과 실제 경과 시간으로 초당 속도 계산

OUTPUT

회전 아이콘, 툴팁, 상세 창에 결과 반영

이 프로그램은 패킷의 내용을 읽지 않습니다. 운영체제가 제공하는 어댑터 단위 누적 카운터를 사용합니다.

02 / Class map

클래스 지도

카드를 누르면 각 클래스의 함수 설명으로 이동합니다.

Program시작점과 메시지 루프MeterContext측정과 이벤트의 중심MeterSettings측정 주기 저장과 복원RateFormat속도 서식과 회전 속도FanArt선풍기 이미지 그리기DetailWindow네 가지 수치를 보여 주는 창

서로 어떻게 연결될까?

Program.Main()
  └─ MeterContext 생성 및 Windows 메시지 루프 시작
       ├─ MeterSettings.Load()     설정 불러오기
       ├─ FanArt.Draw()            아이콘 프레임 만들기
       ├─ RateFormat               수치를 문자열·회전 속도로 변환
       ├─ DetailWindow             상세 창 생성 및 값 전달
       └─ Windows API / .NET       어댑터·트레이·테마 조회

들여쓰기는 소유 관계만 뜻하지 않습니다. MeterContext가 다른 클래스를 생성하거나 그 함수를 호출하는 방향을 간단히 나타낸 것입니다.

03 / Data flow

속도 하나가 표시되기까지

  1. 시작

    Program.Main()이 MeterContext를 만들고 Windows Forms 메시지 루프를 실행합니다.

  2. 측정

    sampleTimer가 MeterContext.Sample()을 호출합니다. 이 함수는 CurrentInterface()로 선택된 어댑터를 가져옵니다.

  3. 변화량 계산

    현재 누적값과 이전 누적값의 차이를 Stopwatch로 잰 실제 경과 시간으로 나눕니다. 수신·송신별 패킷과 바이트, 총 네 값을 계산합니다.

  4. 표시용 변환

    RateFormat이 숫자를 p/s, KB/s 같은 문자열로 바꾸고, 수신·송신 바이트 속도의 합을 회전 속도로 바꿉니다.

  5. 화면 갱신

    Sample()이 툴팁과 열린 상세 창을 갱신합니다. 별도의 animationTimer는 회전 속도를 이용해 알림 영역의 아이콘 프레임을 바꿉니다.

첫 측정은 왜 --일까?

속도를 계산하려면 비교할 이전 누적값이 필요합니다. 시작 직후, 어댑터 변경 직후, 카운터가 감소한 경우에는 우선 기준값을 저장하고 다음 측정부터 속도를 표시합니다.

04 / Events

타이머와 이벤트

타이머 간격은 목표 간격이며 실제 호출은 Windows 메시지 루프의 상황에 따라 달라질 수 있습니다.

계기호출되는 함수와 결과
sampleTimer.TickSample() · 사용자가 정한 100~60,000ms 주기로 통계를 읽습니다. 기본값은 1,000ms입니다.
animationTimer.TickAnimate() · 33ms 간격으로 회전 위치를 갱신합니다. 회전 속도가 0이면 타이머를 멈춥니다.
themeTimer.TickRefreshTheme() · 2초마다 시스템 테마를 확인하고 바뀌었다면 아이콘을 다시 만듭니다.
아이콘 왼쪽 클릭ShowDetails() · 상세 창을 만들거나 기존 창을 활성화합니다.
아이콘 메뉴 열기BuildMenu() · 현재 어댑터 목록과 설정·종료 메뉴를 구성합니다.
사용자 메뉴 선택SelectInterface(), ConfigureInterval() 또는 ExitThread()가 실행됩니다.
05 / Reference

클래스와 함수

생성자와 Windows에서 가져오는 함수까지 포함한 목록입니다. public은 다른 코드에서 호출할 수 있고, private은 클래스 내부에서만 사용합니다. 이 프로그램의 클래스 자체는 모두 internal입니다.

06 / Under the hood

계산과 회전의 핵심

누적값 → 초당 속도

예를 들어 수신 바이트 누적값이 1초 동안 2,048만큼 늘었다면:

(현재 누적값 - 이전 누적값)
÷ 실제 경과 시간
= 2,048 B/s = 2 KB/s

설정 주기가 정확히 지켜졌다고 가정하지 않고 Stopwatch의 경과 시간을 사용합니다. 패킷은 유니캐스트와 비유니캐스트 카운터를 합산합니다.

전송량 → 선풍기 회전

수신과 송신의 바이트/초를 합쳐 회전 속도를 정합니다. 음악이나 게임 다운로드를 구별하지는 않습니다.

48개 프레임으로 120°를 표현합니다. 날개가 세 개라 120°를 돌면 겉모양이 반복되기 때문입니다.

실제 이미지는 SVG나 GIF 재생이 아니라, 미리 만든 Windows 아이콘을 교체해서 표시합니다.

이름 붙인 기준값 · v8에서는 측정 주기 범위를 MinimumIntervalMs와 MaximumIntervalMs로, 회전 기준 전송량을 ReferenceBytesPerSecond로, 프레임 수를 FrameCount로 관리합니다.

기억해 둘 상태 변수

변수의미
previousReceivedPackets / previousSentPackets이전 수신·송신 패킷 누적값
previousReceivedBytes / previousSentBytes이전 수신·송신 바이트 누적값
receivedPacketsPerSecond / sentPacketsPerSecond / receivedBytesPerSecond / sentBytesPerSecond가장 최근에 계산한 네 가지 초당 속도
selectedAdapterId / previousAdapterId사용자 선택 ID와 마지막으로 측정한 어댑터 ID. 자동 선택이면 selectedAdapterId는 null.
hasValidSample이전 측정값과 비교해 유효한 속도를 계산했는지 여부
animationPhase / currentFrameIndex반복되는 120° 구간 안의 회전 위치와 실제 표시할 아이콘 번호
자동 어댑터 선택의 범위

자동 선택은 “게이트웨이가 있는 첫 번째 활성 어댑터”입니다. 운영체제의 라우팅 우선순위를 판별해 반드시 실제 기본 경로를 찾는 구현은 아닙니다. 필요하면 메뉴에서 어댑터를 직접 선택할 수 있습니다.

07 / Reading path

코드를 따라 읽는 순서

  1. 15~27행: Main()이 어디서 시작해 무엇을 만드는지 확인합니다.
  2. 218~270행: MeterContext의 필드와 생성자에서 타이머와 이벤트 연결을 봅니다.
  3. 272~355행: 어댑터 선택부터 Sample()의 속도 계산과 화면 갱신을 따라갑니다.
  4. 78~179행, 358~419행: 회전 속도 계산 → 프레임 그리기 → 애니메이션과 테마 갱신을 읽습니다.
  5. 182~215행, 422~523행: 상세 창, 메뉴, 설정 대화상자와 종료 정리를 확인합니다.
